How it works

Two ways to run every model — pick whichever suits you.

1

Pick a model

Smaller models are quicker and fit any computer. Bigger ones know more but need more memory. The coloured dot tells you what fits yours.

2

Run it in Oriel

Press Run in Oriel and the model downloads into this browser once, then answers straight from your graphics chip. Close the tab and it's still there next time.

3

Or run it anywhere

Every model page shows the one command to download it with Ollama, or where to find it in LM Studio — free apps that run models on your computer.

Is it really private?

Yes. When you run a model in Oriel, it runs inside your browser on your own device. Your messages are never sent to a server — not ours, not anyone's. Your chats are saved only in this browser.

Why is the first time slow?

The model has to download once — from about 0.2 GB for the smallest up to 5 GB. After that it's stored in your browser and starts in seconds.

Which browsers work?

Running models in the browser needs WebGPU: recent Chrome or Edge on Windows, Mac, Linux or Chromebook, and Safari 26 or newer on a Mac. Phones can run the tiny models. Downloading to run anywhere works from any browser.

Which model should I pick?

Start with Qwen3 4B if your computer has 8 GB of memory or more, or Llama 3.2 1B on an older one. For programming, try Qwen2.5 Coder 7B. To run on your computer with Ollama, Gemma 4 E4B is a great all-rounder that also reads photos.

Can I use these models for my business?

Most, yes — each model shows its licence in plain words. A few are for personal and research use only, and they're marked.

How do I free up space?

Use Manage in the “Your device” box to delete models downloaded in this browser. Clearing your browser's site data for this page also removes them.
